## v0.1.2 — 2026-09-23

**SemVer: patch** — consolidates the ExternalObject adapter's return-value
helpers on ESABI v0.3.0's canonical value setters without changing the VectorIPC
C ABI, wire protocol, adapter command surface, or ExtendScript wrapper API.

### Changed

- The adapter's return-value helpers now call `esabi_value_set_undefined()` and
  `esabi_value_set_string()` instead of assigning `esabi_value` fields directly.
- This removes the last duplicated field-level writes from the adapter; ESABI
  remains the sole definition of the host ABI boundary.
- No behavioral change: the ESABI setters perform the same reset, type-tag, and
  reserved-field writes, and they are NULL-safe like the helpers they replace.
