## v0.1.0 — 2026-09-23

**SemVer: minor** — first public pre-release of VectorIPC; establishes the initial product, ABI, wire, native, and ExtendScript surfaces.

Gate: 11/11 Release CTest targets / 500,000 protocol codec cases / 11/11 MSVC AddressSanitizer targets / 16 MiB exact payload boundary / 100,000 full-duplex messages in each direction / 1,000,000-frame soak / live Adobe Illustrator 30.6.0 adapter + wrapper ecosystem verification. All green on this release tree.

### Added

- `VIPC/1.0`: a fixed 32-byte little-endian wire envelope with opaque application payloads and a 16 MiB native payload cap.
- C ABI v1 with fixed-width public scalar types and compile-time size/offset assertions for public structures.
- Header-only C++17 move-only ownership façade over the same C ABI.
- Persistent Windows named-pipe client/server transport with one concurrent send and one concurrent receive per channel.
- Whole-operation deadlines, bounded cancellation settlement, poisoned-channel semantics after ambiguous I/O, and listener recovery after transient pre-accept disconnects.
- Current-user Windows DACLs, local-only pipe rejection, session-scoped endpoint names, and peer PID/session metadata.
- ExternalObject adapter v3 with 16 generation-tagged logical sessions and a 256 KiB adapter payload cap.
- ExtendScript wrapper v5 with raw binary/string lanes plus optional ESON, ESB64, and ESCHARS composition.
- CMake install/export package as `VectorIPC::vectoripc`, independently exercised by C11 and C++17 consumers.
- Reproducible release manifest tooling with per-file and aggregate SHA-256 digests and a tagged source archive.

### Validation

- Protocol fuzz: 250,000 valid encode/decode round trips plus 250,000 mutated 32-byte headers.
- Timeout stress: 2,000 cycles with process handles stable at 59 → 59.
- Accept/write cancellation: 2,000 accept cancellation cycles plus 500 blocked-write cancellations, handles stable at 59 → 59.
- Full-duplex stress: 100,000 messages in each direction.
- Soak: 1,000,000 verified small frames plus a 256 KiB payload soak.
- Live host: Adobe Illustrator 30.6.0 build 109R verified adapter INFO/binding, raw arbitrary-byte transport, high-level wrapper behavior, session isolation, UTF-8 validation, and ESON + ESB64 + ESCHARS composition.

### Security

- Windows endpoints are restricted to the current user, reject remote clients, and are scoped by Windows session.
- Clients request `SecurityIdentification`; VectorIPC does not grant pipe-based impersonation.
- Invalid magic/version/header size/kind/flags, oversized payloads, malformed/truncated streams, and uncertain cancellation states fail closed.
- Same-user processes remain inside the OS trust boundary; stronger application authentication belongs in the application handshake above VectorIPC.

### Compatibility

- Supported release target: Windows x64, C11 core, C++17 façade.
- Live-certified adapter target: Adobe Illustrator 30.6.0 ExternalObject.
- Native Adobe `.aip` consumers use the same C/C++ API, but that host path is not separately certified in v0.1.0.
- macOS/POSIX intentionally builds an unsupported stub in v0.1.0; a Unix-domain transport is planned.
- The CMake package uses `SameMinorVersion`; the package smoke test verifies that 0.1.0 satisfies 0.1 but not 0.2.
