## v0.1.1 — 2026-09-23

**SemVer: patch** — canonicalizes VectorIPC's Adobe ExternalObject ABI boundary
on ESABI v0.3.0 without changing the VectorIPC C ABI, wire protocol, adapter
command surface, or ExtendScript wrapper API.

### Changed

- Removed VectorIPC's duplicated private definitions for ExternalObject
  `TaggedData`, type tags, errors, packing, calling convention, and lifecycle
  entry points.
- VectorIPC now builds its ExternalObject adapter against
  [ESABI v0.3.0](https://github.com/thelabcorner/esabi/releases/tag/v0.3.0),
  using `esabi_value`, `ESABI_*` type constants, and ESABI's export macros as
  the single host-ABI definition.
- CMake accepts an installed `esabi::esabi` package only at exactly `0.3.0`;
  otherwise it fetches the peeled v0.3.0 commit
  `3e99040c43cef573b477ad372b2a3a96c4d3a7d7`.
- Corrected `ESInitialize` to ESABI's documented single value-array pointer
  signature. VectorIPC never dereferenced that argument, so this is an ABI
  declaration correction rather than a behavioral change.
- ExternalObject smoke and logical-session tests now compile against the same
  ESABI definitions as production code.

### Compatibility

| Product version | `0.1.1` |
| C ABI | `1` — unchanged |

| ESABI dependency | `v0.3.0` / `3e99040c43cef573b477ad372b2a3a96c4d3a7d7` |

No wire bytes, operation IDs, payload limits, endpoint semantics, session-handle
format, wrapper commands, or C/C++ transport APIs changed.

candidate.

- Installed package: independent C11 and C++17 consumers passed; the package
  does not vendor ESABI's headers, CMake package, or license tree.
- MSVC static analysis: pass.
- MSVC AddressSanitizer: 11/11 targets passed.
- Exact transport boundary: 19 payload sizes through 16 MiB passed.
- Timeout/cancellation stress: 2,000 cycles, process handles 59 → 59.
- Accept cancellation/recovery: 2,000 cycles, process handles 59 → 59.
- Blocked-write cancellation: 500 cycles, process handles 59 → 59.
- Full duplex: 100,000 messages in each direction.
- Small-frame soak: 1,000,000 verified frames.
- 256 KiB soak: 50,000 verified frames at about 1.71 GiB/s duplex payload on
  the final qualifying run.
- Live Adobe Illustrator 30.6.0: INFO/binding, raw binary, wrapper, logical
  sessions, and ESON + ESB64 + ESCHARS composition all passed.
